Acreline · v1.2.2

Theme documentation

Acreline is a WordPress theme for farms, land, and historic homes: searchable listings, agents, and showing requests. This folder is the buyer documentation that ships in the ThemeForest / own-site pack.

Fiction only. Sample listings, 555 phones, and @acreline-concept.test emails are concept data. This is not a live MLS, licensed brokerage, or booking desk.

Install

Extract the pack, upload inner acreline.zip, set Identity, optional child + Core, then seed demo content.

Customizer

Brand, phone, colors, header, typography, social links, and removable footer credit.

Listings

Listing / agent / booking fields, ?listing_id= showing links, and Acreline Core.

Support

Where to get help. Demo phones do not ring. GitHub issues for reproducible theme bugs.

Pack contents

Do not upload the outer acreline-*.zip in WordPress. Extract it first.

acreline.zipParent theme — Appearance → Themes → Upload Theme. Folder must stay acreline.
acreline-child.zipOptional child theme so CSS survives parent updates.
acreline-core.zipOptional plugin. Keeps listings, agents, and bookings if you switch themes.
Documentation/This HTML set. Start here.
Demos/How to seed or import demo content. Photos are not bundled.
