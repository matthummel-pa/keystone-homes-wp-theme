Acreline · Buyer documentation

Install and match the demo

This theme is a land-and-farms realtor concept. Sample phones are 555 numbers. It is not a live MLS or licensed brokerage.

Pack contents. Use keystone-homes.zip in Appearance → Themes. Optional: keystone-homes-child.zip, keystone-core.zip (listings survive a theme switch).

1. Install

  1. WordPress 6.6+ and PHP 8.3+.
  2. Upload and activate keystone-homes.zip. The folder name must stay keystone-homes.
  3. Activate Keystone Core if you shipped the plugin. Skip this on the public concept site — the theme still registers listings as a fallback.
  4. Optional: activate the child theme so your CSS lives through parent updates.

2. Identity

Go to Appearance → Customize → Identity. Set brand name, phone, email, address, hours, and the header button. Upload a logo under Site Identity.

Uncheck Show concept demo banner and Show removable studio credit before a client preview. Footer copyright is always the site name and year.

Accent color: Customize → Colors. Fonts: Customize → Typography (Inter by default, Google Fonts).

3. Menus and widgets

Appearance → Menus: assign Primary and Footer. Seed creates those menus if they are missing. Appearance → Widgets → Footer is optional.

4. Demo content

Preferred: Tools → Seed Acreline demo (or wp ks seed). Safe to run again — slugs update, they do not duplicate.

That creates Home, Listings, Areas, Guide, Agents, Contact, Book a showing, Blog, sample listings, agents, and menus.

5. Listings and showings

Edit Listings and Agents from wp-admin (custom fields, not the block editor). Showing requests POST to keystone/v1/bookings and land in Bookings (Requested → Confirmed → Completed).

Booking links use ?listing_id=123. Do not use ?listing= as a public query.

6. SEO plugins

The theme prints native title, description, canonical, Open Graph, and Twitter tags. If Yoast, Rank Math, SEOPress, or AIOSEO is active, native tags yield. Do not add a second SEO panel in the theme.

7. Child theme

Put CSS in the child style.css. Do not edit parent Blade or PHP if you want clean updates from the theme-latest zip.
