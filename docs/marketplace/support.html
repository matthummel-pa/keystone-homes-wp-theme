Before you write

Keep the theme folder named acreline. Identity and colors are under Appearance → Customize. Demo phones are 555 numbers; @acreline-concept.test does not reach a real inbox.

This theme does not sync an MLS, take payments, or run a real booking desk. The block editor is off on purpose.
