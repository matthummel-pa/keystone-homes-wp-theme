Acreline — WordPress theme pack
================================

For a regular WordPress install (Appearance → Themes → Upload Theme):

  1. Confirm the host has WordPress 6.6+ and PHP 8.3+.
  2. Upload  acreline.zip  and activate Acreline.
  3. Keep the theme folder named acreline.
  4. Appearance → Customize → Identity for brand, phone, and colors.
  5. Optional: acreline-child.zip, then acreline-core.zip.

Do not upload this whole pack zip into WordPress. Extract it first.
WordPress only accepts the inner theme zip (style.css at acreline/style.css).
